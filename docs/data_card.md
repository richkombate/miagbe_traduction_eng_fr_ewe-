# Data Card

## Sources prévues

- FLORES-200 : validation/test multilingue.
- OPUS/JW300 : corpus parallèle, notamment pour ewe-anglais.
- Bible parallèle : source utile mais biais religieux à documenter.
- Données locales : phrases validées par locuteurs ewe.

## Nettoyage

- Normalisation Unicode NFC.
- Suppression espaces multiples.
- Conservation des caractères ewe : ɖ, ɛ, ƒ, ɣ, ŋ, ɔ, ʋ.
- Dédoublonnage.
- Filtre longueur.

## Limites

Les corpus religieux ou institutionnels peuvent limiter la généralisation vers le langage quotidien.
